# Fase 1: Preparación del repositorio

## Objetivo

Dejar el repositorio listo para comenzar el proyecto y establecer una base reproducible para las sesiones con alumnos.

## Actividades

1. Verificar Java 21, Maven, Docker y Docker Compose.
2. Documentar prerrequisitos y comandos de verificación en el README.
3. Crear la estructura de documentación y acordar convenciones de nombres, ramas y variables de entorno.
4. Añadir archivos de ejemplo para configuración local, sin secretos reales.

## Resultado verificable

Un alumno puede comprobar sus herramientas y entender cómo se organizará el proyecto antes de generar código Spring.

## No incluye

No se crea aún la aplicación ni se levanta ninguna base de datos.
