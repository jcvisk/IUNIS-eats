# Fase 2: Bootstrap de Spring Boot

## Objetivo

Crear la aplicación base y explicar la estructura de un proyecto Spring Boot con Maven.

## Actividades

1. Generar el proyecto con Java 21 y las dependencias iniciales: Web, Thymeleaf, Validation, DevTools y Actuator.
2. Explicar `pom.xml`, la clase principal, paquetes y perfiles de configuración.
3. Crear una ruta de salud y una vista Thymeleaf mínima.
4. Ejecutar la aplicación localmente y validar el arranque.

## Resultado verificable

La aplicación inicia con Maven y responde una página HTML renderizada por Thymeleaf.

## No incluye

Persistencia, autenticación ni funcionalidades del negocio.
