# Fase 5: Thymeleaf y base PWA

## Objetivo

Establecer el diseño común de las vistas y hacer instalable la aplicación como PWA.

## Actividades

1. Crear layout, fragmentos de navegación, estilos y manejo de mensajes de validación.
2. Diseñar las pantallas base de estudiante y personal, aún sin lógica completa de negocio.
3. Añadir manifest, iconos y service worker para caché de recursos estáticos seguros.
4. Probar instalación y funcionamiento básico sin conexión de la shell visual.

## Resultado verificable

La aplicación es navegable, responsive e instalable desde un navegador compatible.

## Regla

Los datos sensibles y acciones autenticadas no se guardarán en caché offline.
