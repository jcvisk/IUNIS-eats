# IUNIS-eats

## Conexión a PostgreSQL

Configura `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USERNAME` y `DB_PASSWORD` en el
archivo `.env` de la raíz del proyecto. La aplicación lo carga al iniciarse
desde esa carpeta. Las variables de entorno del sistema tienen prioridad.
El archivo `.env` está excluido de Git.
